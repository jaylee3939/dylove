# Real memory photos

Place your own photographs here, for example `tokyo-01.jpg`, then replace a `null` entry in `src/data/memories.ts` with `/memories/tokyo-01.jpg`.
Each stage supports multiple photos. Use portrait or square JPEG/WebP under 1500 pixels where possible. Missing photos render a Korean empty keepsake frame; no fake personal photographs are included.
Only include photographs you want to share with anyone who can access the published game.
